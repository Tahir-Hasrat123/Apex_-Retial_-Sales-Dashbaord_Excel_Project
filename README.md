# 📊 APEX RETAIL SALES & PROFIT ANALYSIS DASHBOARD

## 🚀 Project Overview

I am excited to share my **Apex Retail Sales & Profit Analysis Dashboard**, developed using Microsoft Excel as part of my journey into Data Analytics.

This project focuses on transforming raw retail sales data into meaningful business insights through data organization, analysis, visualization, and interactive dashboard development.

The dashboard provides a clear overview of retail business performance, helping users understand sales trends, profitability, product category performance, regional sales, and customer payment preferences.

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze total sales and profit performance.
- Identify sales performance across different regions.
- Evaluate the top-performing sales representatives.
- Analyze product category profitability.
- Understand sales quantities by payment method.
- Monitor sales trends over time.
- Build an interactive dashboard for business decision-making.

## 📈 Key Performance Indicators (KPIs)

The dashboard highlights two important business metrics:

- 💰 **Total Profit:** $15,256
- 📦 **Total Quantity Sold:** 260 units

## 📊 Dashboard Features

The dashboard includes the following visualizations:

1. **Sales by Region:** Compares sales performance across East, North, South, and West regions.
2. **Top 5 Salespersons:** Provides a view of sales representative performance.
3. **Profit by Category:** Shows profit distribution across Clothing, Electronics, Furniture, Home Decor, and Sports.
4. **Sales Trend:** Visualizes sales performance over time.
5. **Quantity by Payment Mode:** Compares quantities sold through different payment methods.

## 🎛️ Interactive Dashboard Features

I implemented Excel Slicers to make the dashboard interactive and user-friendly.

Users can filter the data using:

- 🌎 Region
- 💳 Payment Mode
- 🛍️ Product Category

These interactive filters allow users to explore different business segments and analyze performance dynamically.
